# Security policy

## Supported versions

Security fixes are provided for the latest published minor version of `client-parser`.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Email a report to [montasimmamun@gmail.com](mailto:montasimmamun@gmail.com) with reproduction steps, affected versions, and potential impact.

You should receive an acknowledgment within 72 hours. After verification, we will coordinate a fix and responsible disclosure with you.

## Scope

User-Agent strings and HTTP headers are untrusted input. Reports involving excessive CPU or memory consumption, unsafe parsing, package supply-chain behavior, or unexpected data disclosure are particularly helpful.
