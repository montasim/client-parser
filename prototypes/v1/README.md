# client-parser prototype · v1

A self-contained product-site and documentation prototype based on `client-parser` v0.1.0.

## Preview

Open `index.html` directly, or serve the directory locally:

```sh
cd prototypes/v1
python3 -m http.server 4173
```

Then visit `http://localhost:4173`. The package-manager switcher, copy actions, responsive navigation, sample User-Agent controls, live result preview, and docs navigation are interactive.

The playground contains a lightweight browser-only approximation for presentation purposes. Production parsing should use the published `client-parser` package.
